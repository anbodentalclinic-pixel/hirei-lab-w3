# 比例ラボ 第3週

中学1年 数学「4章 比例と反比例」の反比例と文章題(利用)用の練習ゲームです。
授業より先に家で反比例に出会う前提で、「なぜ反比例か」を自分で見つけるところから始めます。

## ステージ

| ステージ | 内容 |
|---|---|
| 反比例ってなに? | あめ・長方形・ひもで x を変えて表を作り、「x × y がいつも同じ」を見つける |
| 反比例の式 | 表の計算と、形→代入→かっこ→符号→計算→たしかめ で y = a/x を求める |
| 反比例のグラフ | 方眼に点を打って双曲線を作る/グラフが通る点から式を求める |
| 文章題クエスト | 比例・反比例の文章題を動く絵で「何を聞かれているか」をつかんでから、6ステップ(線→ことばの式→表→式→たしかめ→答えの文)で最後まで解く |
| ボス戦 | 全部まぜて8問、ハート3つ |

合言葉①「1行に1ステップ」・②「答えの文まで」・③「もとに戻して たしかめる」を、ヒントと結果画面でくり返し表示します。
